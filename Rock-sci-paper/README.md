# Rock Paper Scissors ✊📄✂️

A simple **Rock Paper Scissors** game built using **HTML**, **CSS**, and **JavaScript** as part of my frontend learning journey.

## Features

- Play against the computer
- Random computer choices using `Math.random()`
- Winner determination using conditional logic
- User input handling
- Clean and beginner-friendly JavaScript code

## Concepts Practiced

- Variables
- Functions
- Conditional statements (`if`, `else if`, `else`)
- String methods
- `Math.random()`
- User input with `prompt()`
- JavaScript logic and program flow

## How to Play

1. Open the project in your browser.
2. Enter one of the following when prompted:
   - `rock`
   - `paper`
   - `scissors`

3. The computer will randomly choose its move.
4. The game compares both choices and displays the result.
